# Iris Dataset Data Visualization

## 📌 Project Overview
This project focuses on visualizing patterns and relationships in the Iris Dataset using Python visualization libraries. The goal is to understand feature distributions, compare species characteristics, and identify relationships between variables through graphical analysis.

The project includes:
- Bar Chart
- Histogram
- Scatter Plot
- Feature comparison and analysis

---

## 🎯 Objective
- Visualize patterns in the Iris dataset
- Compare different flower species
- Understand feature distributions
- Identify relationships between numerical features

---

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

---

## 📂 Dataset
Dataset Used: **Iris Dataset**

The dataset contains:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

---

## 🔍 Steps Performed

### 1. Data Loading
- Loaded Iris dataset using Seaborn/Pandas
- Checked dataset structure and columns

### 2. Data Visualization
Created multiple visualizations to analyze the dataset:
- Bar Chart
- Histogram
- Scatter Plot

### 3. Feature Comparison
Compared flower species based on:
- Petal length
- Sepal length
- Distribution patterns
- Feature relationships

---

## 📊 Visualizations Included

### ✅ Bar Chart
Compared average petal length among different species.

### ✅ Histogram
Visualized the distribution of sepal length values.

### ✅ Scatter Plot
Analyzed the relationship between sepal length and petal length.

---

## 📈 Key Insights

### Example Insights
- Setosa species has significantly smaller petal lengths compared to other species.
- Virginica species has the largest petal lengths.
- Scatter plots show clear clustering between species.
- Sepal length values are mostly distributed between 5.0 and 6.5.
